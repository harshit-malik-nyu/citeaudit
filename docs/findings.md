# Findings

What three measurements say about where citation integrity actually breaks
down, and what a citeaudit score means.

Every figure here is regenerated by `python scripts/run_studies.py --study all`
against live Crossref, OpenAlex and arXiv. Raw per-check data sits in
[`evidence/`](../evidence/).

---

## 1. The question nobody had answered

A document scores 91%. Is that bad?

Nobody could say, because no base rate existed. Retraction coverage reports
incidents — Deloitte's refund, EY's withdrawn study — but an incident count is
not a rate, and without a denominator there is no way to tell an alarming
document from an ordinary one.

Three measurements close that gap. The order matters: each one is only
interpretable because of the one before it.

---

## 2. Separating the instrument from the signal

The first study measures **the tool's own error rate**; the second measures
**the world's**. Running them in the other order would be useless, because
without knowing how often citeaudit is wrong there is no way to attribute
anything it reports.

### Study 1 — publisher-deposited references

[Full report](../evidence/baserate/report.md) · 614 checks, 72 randomly
sampled papers, stratified by publication year

Ground truth comes free from the construction. Take real published papers and
their deposited reference lists; every entry carries a DOI, so every cited work
provably exists. Hide the DOI, check by description alone, and **every
NOT_FOUND is a definite false positive.** No labelling, no annotator
agreement, nothing to dispute.

| Mode | False-positive rate | 95% CI | n |
|---|---:|---|---:|
| Reference supplies a DOI | **0.00%** | 0.00–1.24% | 307 |
| Description only | **1.30%** | 0.51–3.30% | 307 |

**Reading:** citeaudit does not meaningfully manufacture false alarms. With
identifiers it produced none at all. Its error contribution to any downstream
measurement is bounded at roughly one percent.

### Study 2 — author-written bibliographies

[Full report](../evidence/preprints/report.md) · arXiv `.bbl` and `.bib`
sources, before any publisher touched them

| | |
|---|---:|
| Unverified rate | **8.87%** |
| 95% CI | 6.25–12.45% |
| Conclusive checks | 327 |

**Reading:** because Study 1 bounds the instrument at ~1%, the remaining ~8% is
attributable to the bibliographies rather than to the checker. That attribution
is the entire reason Study 1 had to come first.

### The gap

| Corpus | Unverified | What produced the reference |
|---|---:|---|
| Deposited, DOI supplied | 0.00% | Publisher pipeline, validated at source |
| Deposited, description only | 1.30% | Publisher pipeline |
| Author-written | 8.87% | A human, by hand |

**Sevenfold.** The same scholarly works, cited into the same indexes. The
difference is not the literature — it is whether anything validated the
reference on its way in.

## 3. What this implies about grey literature

The corpus where fabrication has actually been found has **no pipeline at
all.** Consulting deliverables, government reports and internal memoranda are
written like the third row and checked like nothing.

That is an extrapolation, and it is the load-bearing assumption in the business
case. It cannot be validated directly, because those documents are not publicly
samplable at scale — which is precisely why no base rate for them exists.

So it is **bounded** rather than asserted. Study 3 measures a third corpus
chosen to be as different from arXiv as the public web allows: Wikipedia
citations, written by non-specialists in inconsistent styles, mixing journals
with news, reports, books and bare URLs, with no reference manager anywhere.
See [`evidence/wikipedia/`](../evidence/wikipedia/).

If the rate holds between expert and non-expert author-written bibliographies,
the extrapolation is defensible. If it moves, the spread is the honest error
bar on any claim about a corpus nobody can sample.

One thing that already sharpens the picture: within the author-written corpus,
references carrying a DOI came in at **4.4%** against **9.6%** for
description-only entries. Supplying identifiers halves the rate. That is a free
intervention any organisation can mandate tomorrow, and it does not depend on
the extrapolation being right.

## 4. Why the threshold is what it is

[Full report](../evidence/calibration/report.md) · ~2,500 labelled pairs from
260 real Crossref records

Same-work pairs take a real record and degrade its title the way bibliographies
actually degrade. Different-work pairs attach one paper's DOI to the *nearest
confusable title* in the sample — a plausible title in the right field, which
is what a fabrication looks like. Labels follow from construction, not
judgment.

Precision holds at 1.000 across the entire swept range; recall climbs with the
threshold. Across independent draws the minimum threshold reaching full recall
landed at **62** and at **66**. The configured value is 66, so it holds on both
draws rather than only on the one that produced it.

The operating point is chosen on a **precision floor**, not by maximising F1.
F1 treats the two errors as equally costly. They are not: a false accusation is
what makes someone switch the tool off, and a tool that is off catches nothing.

Worth naming precisely: the threshold governs **recall**. Precision is
protected by a different mechanism — the author-overlap corroboration rule in
`match.assess`, which blocks an accusation whenever the claimed authors agree
with the record regardless of title similarity.

## 5. The error that proves the point

The first calibration run returned precision *and* recall of 1.000 at every
threshold from 54 to 90.

That looked like success. It was a failed measurement. Positives had been built
by pairing random titles from unrelated fields, so the two classes never
overlapped and no threshold had anything to adjudicate. Worse, a test had been
written asserting the classes *were* separable — encoding the exact defect it
should have caught.

The labelled set was rebuilt around nearest-neighbour confusions. The report now
states explicitly whether the classes overlap, so a future perfect score is
visibly either earned or meaningless.

**A second, graver one.** A live run reported 8 mismatches, and the README
claimed all 8 were genuine. Nobody had looked. Inspection found **seven were
the tool's own false accusations**: title extraction produced debris — an
identifier, a page range, an author list — which was compared against the real
title, scored 13–20%, and reported as citing the wrong paper.

Root cause: `Proc. R. Soc. Lond. B, 271 (1547): 1443` has an *issue number* of
1547, which matched as a publication year.

A project about unverified claims had published an unverified claim. The
correction is documented in the README rather than quietly edited out, because
deleting it would be the same failure one level up.

---

## 6. The one genuine mismatch

Of the eight, one survived inspection:

| | |
|---|---|
| Identifier | `10.1016/j.energy.2023.128204` |
| Reference claims | *Oklo Inc. (OKLO) Fission Impossible* |
| Crossref record holds | *Uncertainties in estimating production costs of future nuclear technologies* |

The DOI resolves. A reviewer clicking it lands on a real article in a real
journal. It is still not the source the citing text described — which is the
failure mode no link checker can see, and the reason this tool compares
metadata rather than checking HTTP status.

## 7. What would change these conclusions

- **A larger preprint sample.** 327 conclusive checks leaves a 6.25–12.45%
  interval. The sevenfold multiple is directionally safe because the intervals
  do not overlap, but the point estimate could move.
- **A genuinely grey-literature corpus.** Wikipedia is a proxy for a proxy.
  Sampled consulting or policy reports would replace the extrapolation with a
  measurement.
- **A published incident-rate study.** The 5× under-reporting multiplier in the
  [business case](business-case.md) is unknowable from public data by
  construction and is the weakest number in this repository.
- **Quote verification at scale.** Currently limited by open-access
  availability. Most scholarly text is paywalled, so most quotations cannot be
  refuted at all.
